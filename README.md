# 相声师承谱系

根据公开资料整理的中国相声演员师承谱系，从清末到当代，收录正式师承，代拉、引保代/口盟，亲缘，如有出入请多包涵。

当前收录 2054 人、2531 条关系（含 320 条固定搭档：169 条确定、151 条存疑）。图中画出有关系的 2053 人；只有 1 人没有任何关系，不画出。未收录的名字和原因见 `data/excluded.csv`。图谱有三种看法：家谱式谱系图（`#tree`，可按朝代或按活跃年代）、2D星云图（`#nebula`，旧名星云图）和 全景星云图（`#3d`，原来的全网络；`#graph` 仍打开它）。聚焦仍是 `#graph/人物编号`。京剧为主的梨园谱系在 [`liyuan/`](liyuan/)。

人物详情和关系表可展开查看关系依据；相声图中也可点关系线。补充交叉核对按关系 ID 保存于两套图谱各自的 `data/relationship-evidence.json`。来源不同不等于证人独立，传艺也不等同于有正式拜师记录。补充核对仅覆盖部分关系，原标注为存疑的关系保留存疑线。

### 1949 年以后团体
打开 `#organizations` 可按团体、记录类别和姓名查阅逐条出处。图谱可选择最新公开归属、历史或演出记录；人物需已有图谱节点才可高亮。旧名录不等于现任，节目单只证明演出，除非资料明确写出团内身份。已离团者只在历史范围高亮；遇到同名或未建节点，只保留有据的名册记录，不据师承猜测、不添加连线。现有团体记录独立维护于 `data/organizations.json`。德云社旧名录有直属及一至八队，另以2026年演出、报道和离团公告核对；军队及铁路旧单位只记有据的历史关系，不代表现行组织人事。未收录不是没有。

谱系图和 2D 星云图的人物节点不可拖动，画布仍可平移缩放；全景星云图（旧地址 `#3d`）保留节点拖动。

### 亲属资料补录
`data/kinship-updates.json` 保留本轮补录的人物、关系、显示坐标与逐条出处，网页把它与原始数据合并。本轮核对了侯、常、马几家，不承诺全库所有亲属都已核验。亲属线不会参与师承分代；在谱系图勾选「亲属」并点「应用关系筛选」即可查看，并可点线看来源。明载与由已核实近亲关系推得的条目在备注里区分。

关系筛选先暂存勾选，点「应用关系筛选」一次更新图，支持撤销未应用修改。谱系布局不按勾选重新分代；三种视图采用同一组已应用的关系选项。

### 全名单关系与生平初筛
本轮以现有 2054 名人物为名单，用模型分组逐名初筛，再对命中的线索定向核查，不能理解为全员已做完整史料考证。补充数据在 `data/relationship-audit.json`，独立保存 41 条新增关系、8 条旧关系复核和 18 人的生平资料。人物详情区分有出处的资料和存疑字段；「关系表」另列待查线索，纯模型线索不当作出处、不入图、不参与师承定位。

### 数据及软件署名

人物、关系和团体的出处在网页对应条目。源自维基百科的内容遵循 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。图谱使用 [Cytoscape.js](https://js.cytoscape.org/)（MIT）；曾交叉核对 [开源《相声家谱》](https://github.com/jammyfu/xiangsheng-genealogy) 中带出处的师承资料（MIT，不含该项目代码）。

### 手机图谱
窄屏按可用视口尺寸适配。图例默认收起；「全屏看图」是独立的显示选项，不改变图谱类型。手机轻点人物打开详情，从节点或空白处单指滑动都平移画布，双指捏合缩放；电脑版全景节点仍可拖动。谱系图放大后按实际溢出显示右侧纵向和底部横向滚动条。
