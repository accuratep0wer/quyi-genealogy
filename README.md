# 相声师承谱系

根据公开资料整理的中国相声演员师承谱系，从清末到当代，收录正式师承，代拉、引保代/口盟，亲缘，如有出入请多包涵。

当前收录 2078 人、2435 条关系（含 295 条固定搭档：144 条确定、151 条存疑）。图中画出有关系的 2077 人；只有 1 人没有任何关系，不画出。未收录的名字和原因见 `data/excluded.csv`。图谱有三种看法：家谱式谱系图（`#tree`，可按朝代或按活跃年代）、2D星云图（`#nebula`，旧名星云图）和 3D星云图（`#3d`，原来的全网络；`#graph` 仍打开它）。聚焦仍是 `#graph/人物编号`。京剧为主的梨园谱系在 [`liyuan/`](liyuan/)。
